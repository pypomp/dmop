# Corrected Dhaka score/SAEM comparison

This is the current paired experiment: 20 global and 20 IF2 starts, 1,000
particles and 850 seconds per arm. `protocol.json` and `source/` freeze the
settings and code. The mathematical complete-path objective is unchanged.
Numerical SAEM uses a fixed positive objective scale within each L-BFGS-B
M-step to avoid the false convergence reproduced in
[the fixed-path diagnostics](../../../code/benchmarks/README.md).

The preceding unscaled experiment is preserved in `../saem_ab/`. Completed
compatible score fits are copied from it, including failures, without
selection by likelihood. `score_reuse.json` records their original file
hashes; their reported fitting times remain unchanged. All SAEM fits in
this directory use the corrected optimizer. Evaluations are rerun with the
declared paired random numbers and never select fitted estimates.

Each `cold/startNNN/` and `warm/startNNN/` directory contains the saved fits,
parameter traces, evaluation replicates and a completion status. A directory
without a complete status is unfinished. Once all 40 pairs are complete,
`report/` contains the panels, table, summaries and provenance generated by
`python -m ditlevsen.saem_ab_report ditlevsen/results/saem_ab_scaled`.
See [the implementation README](../../README.md) for environment and fitting
commands. SI integration requires review of the completed report.
